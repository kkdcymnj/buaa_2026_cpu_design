# 2026《处理器芯片设计实训》课程设计

### 仓库内容

- 本仓库包含了2026《处理器芯片设计实训》课程设计的Verilog源代码。仓库中的代码可以通过chiplab的linux仿真测试。

- 这一CPU核大量参考了openLA500进行设计，但对局部历史的分支预测作了重新实现（不一定对，只供参考），且cache模块的逻辑也比较怪（大概率有小问题）。

- 如果你想要在chiplab环境下运行这份代码，可能需要取消`constant.v`中对`define CHIPLAB`的注释，并对目录下其他顶层模块文件作类似检查。

### 有关课程

- 这门课程强度大小取决于个人：可以直接对挖空后的openLA500进行填空，也可以基于计组课设作大规模改造。不过在AI的协助下，即使是后者应该也不会过于难。

- 期末需要提交设计报告以及对应的PPT。材料一般要求在暑假初期提交。
